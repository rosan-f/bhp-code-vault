# Black Hat Python Code Vault

Repository untuk dokumentasi dan implementasi kode praktikum dari buku *Black Hat Python (2nd Edition)* oleh Justin Seitz & Tim Arnold.

## Tech Stack
- **OS**: Kali Linux
- **Language**: Python 3.x
- **Core Modules**: `socket`, `threading`, `sys`, `subprocess`

## Struktur Repositori
- `ch02_basic_networking/`: TCP/UDP clients, servers, and custom Netcat implementation.
- `ch03_raw_sockets/`: Raw sockets, packet sniffing, and host discovery.
- `ch04_scapy/`: Packet manipulation using Scapy.
- `ch05_web_hack/`: Web app exploitation tools.
